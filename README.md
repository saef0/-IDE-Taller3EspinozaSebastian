Simulación de carrera de caballos

Funcionamiento:
Cada caballo esta asociado a un hilo, de manera aleatoria avanzan de 1 a 10 metros hasta llegar a los 100 metros, cuando los 4 hilos se imprimen las posiciones en la que cada caballo quedo

Ejecución:
Abrir el proyecto con Intelij, ir al main y ejecutar el código
